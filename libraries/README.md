# Custom libraries

Use symbols/, footprints/ and 3dmodels/ for project-owned assets. Register symbols and footprints in the root project library tables using ${KIPRJMOD} paths. FrameworkMechanical is registered for the mounting-hole footprint.

For each imported asset record its name, upstream URL, revision, license, local changes, and affected components here. FrameworkMechanical.pretty/MountingHole_2.2mm_M2.kicad_mod was extracted from the pinned Framework printable PCB and marked board-only/excluded from BOM and placement. See THIRD_PARTY_NOTICES.md and references/framework/manifest.json for source, revision and license.
